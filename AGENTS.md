# Regras do projeto

Escrever a interface em português brasileiro.
Preservar o design e as proporções dos assets fornecidos.
Aplicar SOLID e separar interface, regras de backup e integração com o Revit.
Não incluir comentários ou documentação no código. Documentar apenas no README.
Não salvar nem sincronizar o projeto automaticamente.
Preservar todas as versões de backup e verificar transferências antes de remover a origem.
Executar chamadas da API do Revit apenas no contexto permitido.
Manter navegação por teclado, foco visível e dimensões estáveis dos controles.
